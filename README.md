# 🌍 Lingalo - Master Languages Professionally

Lingalo is a sleek, modern, professional language learning platform designed for mastering Japanese, Korean, French, Spanish, and German through a focused, dashboard-driven experience.

**🌐 Live Demo: [https://cijamie.github.io/lingalo/](https://cijamie.github.io/lingalo/)**

![Lingalo Logo](assets/logo.png)

## 🚀 Features

-   **Multi-Language Support**: Dedicated full-featured curricula for **Japanese (日本語)**, **Korean (한국어)**, **French (Français)**, **Spanish (Español)**, and **German (Deutsch)**.
-   **Modern, Intuitive Navigation**:
    -   **Dashboard**: High-level daily goal tracking, current language stats, language hub with mastery percentages, and one-click practice launch.
    -   **Practice Arena**: Streamlined 1-screen session configurator (Topics + Modes + Options). No confusing multi-step wizards.
    -   **Mastery Matrix**: Interactive curriculum browser showing every character and word with 0–5 star retention scores, category filters, live search, and instant native audio pronunciation.
    -   **Custom Word Bank**: Add custom vocabulary, travel phrases, or notes with automatic translation and bulk import support.
    -   **Settings**: Audio SFX toggle, speech synthesis pronunciation speed slider, daily XP goals, and data backup/reset.
-   **5 Interactive Study Modes**:
    -   🎯 **Quiz Mode**: Rapid multiple-choice practice with keyboard shortcuts (`1`, `2`, `3`, `4`).
    -   🃏 **Smart Flashcards**: 3D flip cards with spaced repetition self-rating (`Again`, `Good`, `Mastered`).
    -   ⌨️ **Typing Practice**: Master spelling and romaji through direct physical or on-screen virtual keyboard input.
    -   ⚡ **Speed Sprint**: 60-second adrenaline drill with rapid-fire questions and multiplier bonuses.
    -   🧩 **Match Pairs**: Interactive 10-card connection game matching foreign words to English definitions.
-   **Gamified Progress**: Track daily streaks, earn XP, level up, and conquer your daily goals.
-   **Spaced Repetition (SRS)**: The app dynamically prioritizes items with lower mastery scores so you retain what you learn.
-   **Data Persistence & Migration**: Local browser storage (`localStorage`) saves your progress securely on your device with automatic migration from older versions.
-   **PWA Ready & Offline**: Installable on desktop and mobile devices with full offline functionality via service workers.
-   **Responsive Design**: Modern dark theme with ambient lighting, glassmorphism, responsive sidebar for desktop, and thumb-friendly bottom navigation on mobile.

## 🛠️ Technology Stack

-   **Frontend**: Vanilla JavaScript (ES6+), HTML5, CSS3.
-   **Styling**: Custom modern CSS with responsive layouts, CSS variables, and ambient dynamic gradients.
-   **Fonts**: Google Fonts (`Inter`, `Noto Sans JP`, `Noto Sans KR`).
-   **Audio**: Web Speech API for native pronunciations + Web Audio API synthesizer for sound effects.
-   **Persistence**: Browser `localStorage` with backward-compatible migration.
-   **Offline Support**: Service Worker (`sw.js`) and PWA Web App Manifest (`manifest.json`).

## 📱 Mobile Installation

Lingalo is built as a Progressive Web App (PWA). To install:
-   **iOS**: Open in Safari -> Share Button -> "Add to Home Screen".
-   **Android**: Open in Chrome -> Tap three dots -> "Install App".
